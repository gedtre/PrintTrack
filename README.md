# PrintTrack

**PrintTrack Desktop** — lietuviška Windows programa spausdintuvų ir kasečių apskaitai.

## Atsisiuntimas

Atverkite [Windows kūrimo vykdymus](https://github.com/gedtre/PrintTrack/actions/workflows/build-windows.yml).
Pasirinkite sėkmingą vykdymą ir skiltyje **Artifacts** atsisiųskite **PrintTrack-Windows-x64**.
Išskleiskite artefakto ZIP, tada **PrintTrack-Windows-x64.zip**, ir dukart spustelėkite **PrintTrack.exe** aplanke **PrintTrack**.
Prisijungimas prie GitHub reikalingas Actions artefaktams atsisiųsti.
Versijos su `v*` žyma taip pat pateikiamos [Releases](https://github.com/gedtre/PrintTrack/releases).

Python, Qt ar kūrimo priemonių naudotojui diegti nereikia.
[Naudojimo instrukcija](desktop/NAUDOJIMAS.txt) · [Techninė informacija](desktop/README.md)

## Funkcijos

Valdymo skydelis, spausdintuvai, kabinetai, kasetės, aiškiai patvirtintas suderinamumas,
sandėlis, išdavimas, operacijų istorija, ataskaitos, CSV ir atsarginės kopijos.
Šviesi / tamsi tema. DEMO atskirtas nuo tikrų duomenų.
Duomenys saugomi `%LOCALAPPDATA%\PrintTrack\data\`.

Windows kūrimo ir EXE paleidimo būseną tikrinkite konkrečiame Actions vykdyme.
Šaltiniai savaime nepatvirtina sėkmingo Windows EXE sukūrimo.

Ankstesnė žiniatinklio sistema išsaugota. Jos dokumentacija: [WEB.md](docs/WEB.md). Desktop programa nuo jos nepriklauso.
