PrintTrack Desktop — lietuviška vietinė spausdintuvų ir kasečių apskaita.

Atsisiųskite **PrintTrack-Windows-x64.zip**, išskleiskite ir paleiskite **PrintTrack.exe**.
Windows 10 / 11, 64 bitų. Python diegti nereikia. Internetas darbui nereikalingas.

Įtraukta: spausdintuvai, kabinetai, kasečių katalogas, aiškus suderinamumo
patvirtinimas, sandėlio operacijos, išdavimas, istorija, ataskaitos,
CSV importas / eksportas, kopijos, šviesi / tamsi tema ir atskira DEMO aplinka.

Tikras inventorius pradžioje tuščias. Katalogo suderinamumas nepatvirtintas.
Duomenys: %LOCALAPPDATA%\PrintTrack\data\.
Programa nepasirašyta skaitmeniniu sertifikatu.
